# Реестр субпроцессоров

**Дата:** 2026-10-05
**Статус:** рабочий реестр для коммерческого запуска

| Поставщик | Назначение | Статус |
|---|---|---|
| Supabase | Auth, PostgreSQL, хранение данных приложения | используется |
| Telegram | публикация и взаимодействие, если подключено клиентом | опционально |
| VK | публикация и взаимодействие, если подключено клиентом | опционально |
| Sentry | диагностика ошибок, если включен в production | опционально |

## Правила
1. В реестре отражаются только фактически используемые production-поставщики.
2. Для каждого поставщика перед коммерческим запуском проверяются условия обработки данных, безопасность, страны/регионы обработки и применимые договорные гарантии.
3. Добавление нового существенного субпроцессора сопровождается обновлением DPA/уведомлениями, если этого требует применимое законодательство или договор.
4. Если поставщик отключен и фактически не используется, его нельзя представлять пользователю как действующего субпроцессора.
